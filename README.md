# Engineering College — Website Project

## Project Overview
Официальный веб-сайт для Engineering College. Выполнен на чистом HTML5, CSS3, Bootstrap 5 и JavaScript (ES6+).

## Page Map
1. `index.html` — Главная страница (Hero-блок, ключевые преимущество).
2. `about.html` — О колледже и каталог учебных программ.
3. `admissions.html` — Условия поступления и таблица цен.
4. `life.html` — Студенческая жизнь и FAQ.
5. `contact.html` — Контакты и форма обратной связи с anti-spam защитой.
6. `registration.html` — Форма подачи заявки с полной клиентской валидацией.

## JavaScript Features
1. **Динамический фильтр программ**: На странице `about.html` можно фильтровать курсы по категориям без перезагрузки страницы.
2. **Кастомный FAQ-аккордеон**: На странице `life.html` реализован интерфейс раскрытия ответов на вопросы.
3. **Клиентская валидация форм**: Формы на `registration.html` и `contact.html` проверяют ввод данных, совпадение паролей и защищены от спама.
